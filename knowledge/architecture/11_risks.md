> Known risks the project accepts, mostly from the Electron stack and its dependencies, and how each is contained. Researched 2026-11-12 from the stack-selection spike.

| #   | Risk                                                                                                                                                                                                                                                 | Likelihood / impact                | Containment                                                                                                                                                                                                                                      |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| R1  | Memory and size. After scrolling a 10,000-row grid the app used about 160 MB (Windows, private working set) to 440 MB (Linux, proportional); installers are 100 to 126 MB. About 270 MB of the Linux figure is the framework itself                  | Certain / low                      | Accepted (AD-17). Budgets and real-hardware numbers come from the performance initiative; the renderer is shell-independent, so a lighter shell stays possible. No lever tried brought the peak under 400 MB without disabling GPU rasterization |
| R2  | The Chromium update treadmill. Electron ships a major roughly every two months, and Chromium security fixes are ours once it is bundled                                                                                                              | Certain / medium                   | Monthly updates behind the regression suite ([regression-suite.md](../../plans/regression-suite.md)), exact pins, grouped Dependabot updates, the capture job on each update (AD-18)                                                             |
| R3  | Privacy drift. Chromium makes default requests the docs do not mention: the selection spike found a spellcheck dictionary request to Google's CDN that a documented hardening set did not stop, and an IPv6 reachability probe that no flag disables | Medium / high                      | AD-18 hardening, a CI network capture on every Electron update with a DNS-name analyzer, and someone reading its output including notices                                                                                                        |
| R4  | Capture gaps. For Electron, the Windows network capture was never run and the macOS one is socket sampling at low confidence                                                                                                                         | Medium / medium                    | Phase 2 plan ([electron-foundations.md](../../plans/electron-foundations.md)): per-process socket sampling on both OSes, validated with a positive control, plus a Linux namespace capture                                                       |
| R5  | The tested binary differs from the shipped one, or the debugging guard has a gap. The guard runs after Chromium begins parsing flags, so a very early attach was not tested                                                                          | Low / medium                       | AD-16: the pipe route tests the exact release binary, the guard refuses debugging without `FOLIO_AUTOMATION=1`, and the early-attach window is a Phase 2 test                                                                                    |
| R6  | Table accessibility is partial. Windows reports the full 10,001-row grid; Linux and macOS report only rendered rows. The focusable element is the scroll container, and NVDA moved cell by cell and announced no "selected" in one crude run         | Certain / medium                   | AD-15: rows have accessible names and every control has a test ID; screen-reader polish is a later initiative. Real DOM keeps the web build accessible by default                                                                                |
| R7  | User-written rule patterns can hang a JavaScript `RegExp` (catastrophic backtracking); the built-in engine has no timeout                                                                                                                            | Medium / medium                    | AD-9: a linear-time engine (RE2 as WebAssembly) or a time-limited worker                                                                                                                                                                         |
| R8  | Money and date correctness in TypeScript. There is no native decimal type, and runtime types are looser than a compiled language's                                                                                                                   | Medium / high                      | AD-7: branded types, checked integer-cent helpers, a lint rule against float arithmetic on money, schema validation at every boundary, and fast-check properties for the locked-month invariants                                                 |
| R9  | npm supply chain. The selection slice's lockfile held 227 packages                                                                                                                                                                                   | Medium / high                      | Install scripts blocked unless allowlisted, a minimum release age, lockfile-only CI installs, pinned actions, a licence check. The shipped app contained only the bundled code (`app.asar` 1.2 MB), not `node_modules`                           |
| R10 | Thin maintenance behind some UI dependencies: TanStack Virtual is founder-led with sponsor funding, and ECharts released once in six months                                                                                                          | Low / medium                       | AD-13 and AD-15 keep both behind boundaries; each has maintained alternatives (Recharts, visx; other virtualizers)                                                                                                                               |
| R11 | Electron main-process attack surface: a Node-enabled process and a preload bridge in an app that opens personal financial files                                                                                                                      | Low / high                         | AD-18: context isolation, sandbox, validated messages, strict content security policy, fuses; imported CSVs are untrusted input                                                                                                                  |
| R12 | Unsigned installers. Windows SmartScreen and macOS Gatekeeper warn on first run                                                                                                                                                                      | Certain / low                      | AD-20: household only for v1, with written instructions. Signing is revisited before any wider sharing                                                                                                                                           |
| R13 | Linux later. The Chromium sandbox needs an AppArmor profile on Ubuntu 24.04 and later; AppImage silently loses it; Wayland, NVIDIA and packaging-format problems recur across Electron majors                                                        | Certain when Linux starts / medium | AD-20: `.deb` first with the default install script, a CI job launching it without `--no-sandbox`, AppImage secondary. Not part of v1                                                                                                            |
| R14 | A web build and a server backend change the privacy model: requests exist, and the IPv6 probe and the capture allowlist change with them                                                                                                             | Low / high                         | AD-19: opt-in, household-controlled, one allowed origin in the content security policy, the capture allowlist updated, H1.12 reworded when it is built                                                                                           |
| R15 | Audit log growth. An append-only log grows with every command                                                                                                                                                                                        | Certain / low                      | Covered by the AD-1 size and open-time budget once the performance-testing initiative sets it up; retention rule set at implementation                                                                                                           |
| R16 | Real hardware is unmeasured. Every performance and memory number came from CI runners without a GPU, a software renderer and, on macOS, a small VM display                                                                                           | Medium / medium                    | The performance initiative measures on real machines; no budget is final until then                                                                                                                                                              |

## Technical debt

The repository still holds a placeholder .NET scaffold from before the stack was chosen. The first task of the scaffold plan ([app-scaffold.md](../../plans/app-scaffold.md)) removes it, along with its CI workflows and Dependabot configuration, and replaces them with the TypeScript workspace.
