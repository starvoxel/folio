> Known risks the project accepts, mostly from its UI dependencies, and how each is contained. Researched 2026-11-05.

| #   | Risk                                                                                                                                                                                                                                                                         | Likelihood / impact | Containment                                                                                                                            |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | FluentAvalonia depends on one maintainer, with no commits since 2026-08-22 and several unanswered bugs                                                                                                                                                                       | Medium / high       | AD-15 isolation and wrappers; fixes and workarounds live in `UI/Fluent/`; its MIT source can be forked if needed                       |
| R2  | Open FluentAvalonia bugs: ContentDialog does not take keyboard focus (#766, Windows and Linux); NavigationView item alignment and selection indicator (#679, #602, #579); text not vertically centred on macOS/Linux (#616); `UseSystemFontOnWindows` ignored at init (#777) | High / medium       | Checked in the stack spike; worked around inside the wrappers                                                                          |
| R3  | Avalonia 12.2 may conflict with FluentAvalonia. 12.2 adds a Fluent2 theme that currently clashes with FluentAvalonia's, and FluentAvalonia has announced no 12.2 support                                                                                                     | Medium / medium     | Stay on 12.1.x (exact pins); revisit per AD-15 when 12.2 ships                                                                         |
| R4  | DataGrid is deprecated (bug fixes only). Open issues include runaway memory growth on Avalonia 12 with large, mixed-text grids (#228), in-cell editor focus (#248) and no UI-automation support for rows and cells (#267)                                                    | Medium / medium     | Edit in side panels, not cells; test 10k rows in the spike; TableView for small read-only tables; accessibility gap noted below        |
| R5  | TableView has no column sorting and does not virtualize columns                                                                                                                                                                                                              | Certain / low       | Use it only for small read-only tables                                                                                                 |
| R6  | CommunityToolkit.Mvvm has one main maintainer and has been quiet since 2026-03                                                                                                                                                                                               | Low / low           | Mostly generated code over a stable API; we could replace it with a small base class                                                   |
| R7  | Accessibility. DataGrid rows and cells are not reachable through UI automation (#267), which also affects screen readers                                                                                                                                                     | Medium / medium     | Track upstream; the automation server (AD-16) gives tests a path that does not depend on UI automation                                 |
| R8  | Paid Avalonia products would weaken privacy. Pro components (Charts, TreeDataGrid) need a per-seat subscription, build-time licence download and embedded licence-validation code; whether shipped apps ever contact Avalonia is unverified                                  | Low / high          | Excluded by constraint ([02_constraints.md](02_constraints.md)); a network-capture test is required before any reconsideration         |
| R9  | No free visual dev tools. Avalonia.Diagnostics was removed in v12; Dev Tools are paid                                                                                                                                                                                        | Certain / low       | Community MIT forks (AvaDiagnostics12) in debug builds only; the automation server's `ui state` covers much of the need                |
| R10 | Audit log growth. An append-only log grows with every command                                                                                                                                                                                                                | Certain / low       | Covered by the AD-1 size and open-time budget once the performance-testing initiative sets it up; retention rule set at implementation |
| R11 | Automation server is a local attack surface                                                                                                                                                                                                                                  | Low / medium        | Off unless `--automation`; loopback only; per-session token readable only by the user; request limits (AD-16)                          |

## Technical debt

None yet. The scaffold's `MainWindow` is a placeholder until the shell is built in the stack spike.
