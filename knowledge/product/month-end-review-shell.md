# PRD area H: App shell and settings

Part of [Folio](month-end-review.md). The app works like a document editor: open a budget file, work in it, and it saves itself.

| ID    | Requirement                                                                                                                                                                                                                                                                 | Priority |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| H1.1  | The start screen puts the last file front and centre with its status: open month, items to review, accounts waiting on imports, and last month closed                                                                                                                       | must     |
| H1.2  | An option opens the last file automatically at launch, skipping the start screen                                                                                                                                                                                            | should   |
| H1.3  | The start screen lists other recent files, Open another file, and New budget file; new-file setup opens as a dialog                                                                                                                                                         | must     |
| H1.4  | The navigation pane lists Overview, Transactions, Reporting, Net worth, Accounts, and Rules & categories, with Settings at the bottom                                                                                                                                       | must     |
| H1.5  | The command bar always offers Import, Undo, Redo and the month picker                                                                                                                                                                                                       | must     |
| H1.6  | The file autosaves every X minutes (configurable in Settings, default 5 assumed) while it has unsaved changes                                                                                                                                                               | must     |
| H1.6a | Save is also available manually at any time (menu and Ctrl+S), and the top bar shows whether the file has unsaved changes                                                                                                                                                   | must     |
| H1.6b | Closing a month, reopening a month, and completing an import save immediately, regardless of the autosave interval                                                                                                                                                          | must     |
| H1.6c | Closing the app or file with unsaved changes saves them, or prompts to Save, Discard or Cancel                                                                                                                                                                              | must     |
| H1.7  | Undo and redo cover edits, recategorizations, rule changes and whole imports; history lasts for the session and is not cleared by saving; closing a month removes only that month's changes from the history, so work in other months stays undoable                        | must     |
| H1.8  | Undo never alters a locked month                                                                                                                                                                                                                                            | must     |
| H1.9  | Settings hold provider profiles, transfer matching window, rolling average length, theme (light, dark, system), autosave interval, close coverage-gap tolerance, review and suspicious-transaction thresholds and opt-in online lookups                                     | must     |
| H1.10 | The app keeps automatic backups of the file                                                                                                                                                                                                                                 | must     |
| H1.11 | A missing, unreadable or corrupt file on open shows a clear error and offers to open a backup                                                                                                                                                                               | must     |
| H1.12 | All financial data stays in the budget file on the user's computers; nothing is sent anywhere unless an opt-in setting is on                                                                                                                                                | must     |
| H1.14 | A hamburger menu icon in the top bar opens a drop-down of the usual actions: New, Open, Open recent, Save, Close file, Undo, Redo, Import CSV, Settings and About                                                                                                           | must     |
| H1.15 | Every hamburger action except New, Open, Open recent and Close file is also reachable without the menu (command bar, navigation pane, or keyboard shortcut)                                                                                                                 | should   |
| H1.16 | On macOS the app also provides a native menu bar menu with at least About, Settings, Quit and the standard Edit items, so Cmd+Q, Cmd+Z and Cmd+S work as expected                                                                                                           | must     |
| H1.17 | For automated testing and agent validation, the app can be started with an automation option that lets local test tooling drive and inspect it; the option opens no network port, is off unless started that way, and a release build refuses debugging attempts without it | should   |

Out of scope in v1: opening the same file on two computers at once is not handled. Flow and rules: backup frequency, retention and location are decided at planning time. Visual design follows the [design notes](month-end-review-design.md), realized with Fluent UI React.

Assumptions (not in the write-up): H1.6 to H1.6c replace "autosave after each change" per review comment (autosave every X minutes plus manual save; the 5-minute default, H1.6b and H1.6c are assumptions); H1.14 and H1.15 follow the review comment that the Windows-first app uses a hamburger menu, not a menu bar; H1.8 (undo never alters a locked month) and H1.11 (corrupt-file error offering a backup) are proposed; because two concurrent editors are unsupported, the app may detect an in-use file and warn, but is not required to. H1.7's per-month undo history (AD-5), H1.16 (macOS native menu) and H1.17 (automation, AD-16) were decided during architecture review (2026-11-05).
