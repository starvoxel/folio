# PRD area S: Setup and accounts

Part of [Month-End Spending Review](month-end-review.md). A new budget file starts with the current month only; trends build as months are closed.

| ID    | Requirement                                                                                                                                                                                                                                                                             | Priority |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| S1.1  | Creating a file asks for a name and produces a budget file that opens immediately                                                                                                                                                                                                       | must     |
| S1.2  | An account has: name, type, provider profile, "include in month-end analysis" flag, and how money moved into it counts (savings / spending / chosen)                                                                                                                                    | must     |
| S1.3  | Account types offered: chequing, savings, credit card, RRSP, TFSA, RESP, other investment, mortgage, other/custom                                                                                                                                                                       | must     |
| S1.4  | Defaults by type: investment types are excluded and count as savings; mortgage is excluded and counts as spending (housing); other/custom asks which at add time                                                                                                                        | must     |
| S1.5  | Each account takes a starting balance dated the day before its first imported transaction                                                                                                                                                                                               | must     |
| S1.6  | The category template step offers Copy from an existing budget file (categories and rules, including provider rules), Detailed household, and Simple                                                                                                                                    | must     |
| S1.7  | After choosing a template, categories can be renamed, added and removed at main and sub level; Income can be renamed but never removed                                                                                                                                                  | must     |
| S1.8  | The last setup step imports the current month's CSVs via the normal import flow ([I](month-end-review-import.md))                                                                                                                                                                       | must     |
| S1.9  | Accounts can be added, edited and archived at any time after setup; an archived account keeps its history and is no longer asked for at close                                                                                                                                           | must     |
| S1.10 | Assets and debts with no CSV (house, car, family loan) are not part of setup; they are added from Net worth ([N](month-end-review-net-worth.md))                                                                                                                                        | must     |
| S1.11 | Setup may be left unfinished; the file opens with whatever was entered and missing steps remain reachable from their normal screens                                                                                                                                                     | should   |
| S1.12 | An archived account can be unarchived at any time; unarchiving never changes a locked month                                                                                                                                                                                             | must     |
| S1.13 | An account that has transactions is never deleted, only archived; an account with no transactions can be deleted                                                                                                                                                                        | must     |
| S1.14 | An archived account is hidden from pickers, the close checklist and coverage checks, and shown under a collapsed Archived list on the Accounts page; an account archived at any point during a month is not included for that month at all (coverage check, close checklist, net worth) | must     |
| S1.15 | An unarchived account is checked again from the first month in which it is active throughout; a gap before that is flagged per I1.13 but never blocks closing, so there is no forced catch-up                                                                                           | must     |
| S1.16 | Each row on the Accounts page opens that account's detail view; rows are not static text                                                                                                                                                                                                | must     |
| S1.17 | The account detail shows the account's current balance, covered-through date, type, provider and analysis setting                                                                                                                                                                       | must     |
| S1.18 | The current balance is the latest known balance (a CSV balance or a confirmed figure) adjusted by later transactions; with none known it says so and offers to enter one                                                                                                                | must     |
| S1.19 | The account detail lists all of the account's transactions across months, filterable by month, category and status                                                                                                                                                                      | must     |
| S1.20 | Review (queue and full pass) can be scoped to one account from its detail view                                                                                                                                                                                                          | should   |
| S1.21 | Import can be started from an account's detail view with that account preselected                                                                                                                                                                                                       | should   |
| S1.22 | Archived accounts remain viewable in the same detail view, read-only except for unarchive                                                                                                                                                                                               | must     |

Flow and rules: setup is a dialog launched from the start screen. Changing an account's analysis flag or transfer treatment after months are closed does not alter locked months.

Assumptions (not in the write-up): S1.12 to S1.15 record the archive rules chosen in review (never deleted once there is history, restorable, no forced catch-up); S1.16 to S1.22 come from the review comment that accounts must be interactive, with per-account review, transactions and balance; the rule that an account archived mid-month is not included for that month, and that its transactions still count in spending and income, is an assumption to confirm; net worth treatment is N1.12; S1.3 (the account type list) and S1.11 (setup may be left unfinished) are proposed; the exact contents of the Detailed household and Simple templates are drafted at planning time and reviewed with Jeremy; an account's type can change only before its first import.
